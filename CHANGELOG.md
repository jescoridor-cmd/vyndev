# Changelog

## Version 1.0.3 — 2026-11-21

### Story
- Replaced the unrelated Furina chapter prose with the novel `Mother Always Cares About Me`.
- Added Kaito, Sera, Nana, Fufu, and Luna character reference details.

- Reader now renders four actual paragraphs for each published page.

- Previous/next chapter navigation only opens published chapters.
- Chapter library distinguishes Published chapters from Outlines.
- Saved page position remains local; first v1.0.3 launch resets old story page progress while preserving profile and companion data.

### Branding and maintenance
- Updated visible version labels to 1.0.3.
- Updated homepage copy to reflect Kaito's slice-of-life novel.
- Preserved the companion chat demo, profile, avatar/background upload, settings, and local data export/import.
- Added reader/library responsive refinements and focus-visible styles.

- Chat AI is still a scripted offline demo and is not connected to a live LLM.
- Guess the Image remains a coming-soon item.
